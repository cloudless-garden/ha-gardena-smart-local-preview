# AGENTS.md

Guidance for coding agents working in this repository: a Home Assistant
custom integration (preview) for GARDENA devices over the gateway's local
WebSocket API.

Follow [CONTRIBUTING.md](CONTRIBUTING.md). It holds the setup, the checks to
run before opening or updating a PR, the code conventions, the wording rules
and the commit rules. They apply to agents the same way as to humans.

In addition:

- Run every check from CONTRIBUTING.md before you open or update a PR.
- Copy license headers from an existing file of the same type instead of
  retyping them.
- Open new PRs as drafts, with one focused change and no "Test Plan" section.
